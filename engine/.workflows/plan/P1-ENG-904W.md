## Goal

registry. It runs on the local research store only, never past 2015-10-16, and never touches Neon.

committed `docs/backtests/2026-10-02-*` set. If Neon's data has moved, the fallback evidence is
recorded instead.

gets a P7a entry with the result and a P7b entry. The branch is pushed and CI is green.

A "none eligible" result is a successful phase. The job is to measure honestly once, not to find a
winner.

### Bug protocol

A **bug** is any of these:
- a crash, a non-zero exit, or a raised exception;
- a re-run file that is not byte-identical (Step 5);
- a date after 2015-10-16 in `-rows.csv` or `-curves.csv`, or any computed number on a later
  session (Step 4c);
- the run date appearing inside any rendered file;
- a §7.6 section missing from the report;
- a row count different from `len(REGISTRY)`;
- an `eligible` flag that contradicts the D8 criteria recomputed from the row (Step 4d);
- a finalist set that differs from D8 recomputed from the rows (top 3 by MAR, ties by id, at most
  one per family);
- an impossible value (negative equity, NaN, max DD > 100%, a candidate window starting before its
  instruments exist or ending after 2015-10-16).

A result you do not like is never a bug. When the run exposes a bug:
1. Stop. Write a failing regression test on synthetic data in the **owning phase's** test file:
   - `test_sim_rules.py` / `test_sim_book.py` (1);
   - `test_allocator.py` (2);
   - `test_book_runner.py` (3);
   - `test_research_store.py` (4);
   - `test_f_index.py` (5);
   - `test_f_rotation.py` (6);
   - `test_f_factor.py` (7);
   - `test_f_swing.py` (8);
   - `test_backtest_dev.py` (9);
   - `test_backtest_dev_report.py` (10);
   - `test_backtest_dev_command.py` (12).
2. Make the smallest fix in the owning module only. Change nothing else.
3. Run the full suite (Step 1b's command). The passed count grows by exactly the regression tests
   you added. Record them.
4. Commit the fix on its own, before the run commit:
   `fix(<package>): <what> (found by the P7a dev run)`. The body gives the symptom, the root cause,
   and the candidate ids whose numbers the fix changes.
5. Delete every generated output (`docs/backtests/*-p7a-dev-exploration*`,
   `docs/plans/*-p7b-preregistration.md`, `$S/rerun`) and restart at **Step 3** with the same
   `<RUN_DATE>`. The registry is unchanged, so Step 2 still holds.
6. Name the fix commit in the run commit body (Step 6) and in the ROADMAP P7a entry (Step 10).

**Not fixable in this phase, so the phase stops (a stop, never a question; plan index D-H):**
- a fix that would edit `backtest/registry.py`, a candidate's params or rules, a `TradeRules`
  preset value, the D8 rule, a threshold or the window guard;
- a fix to a frozen-set file.

Such a fix would change a pre-registered candidate after its result was seen (D6), or a closed
record. Then: delete the generated outputs, do **not** commit the run, write a note (the symptom,
the root cause, the file the fix would have to touch, and why D6 or invariant 3 forbids it) into
the phase log and the completion summary, edit no ROADMAP entry, and end the phase. Do not wait
for an answer.

**Wall time.** If the whole `backtest_dev` run takes more than 60 minutes and phase 12 added no
pool, the result is still valid. Record the time in the readme and add a handoff. Do not
parallelize in this phase.

```python
"""Freshness and wall-clock checks on the P7a outputs (handover D9, index invariants 5 and 6).

usage: python p7a_dates.py <run_date> <file> [<file> ...]

- Every ISO date in a *-rows.csv or *-curves.csv file must be <= DEV_END (a hard failure otherwise).
- In every other file, each date after DEV_END is printed with its line for a manual check: it may only
  define a window or the gate (for example "2015-10-19 -> data end") or the real-money-date note,
  never sit next to a computed number.
- The run date must not appear inside any file (it belongs in file names only). Phase 10's files
  link their siblings, whose names carry the run date, and show each candidate's registry `added`
  date, which is registry data; both are masked before the check (phase 10 Decision 3).
"""

from __future__ import annotations

import re
import sys
from datetime import date
from pathlib import Path

DEV_END = date(2015, 10, 16)
ISO = re.compile(r"\b(\d{4})-(\d{2})-(\d{2})\b")


def masked(text: str, run_date: str) -> str:
    """``text`` without the sibling-file names and the registry `added` cells/lines."""
    text = text.replace(f"{run_date}-p7a-dev-exploration", "<stem>")
    text = text.replace(f"{run_date}-p7b-preregistration", "<prereg>")
    text = text.replace(f"| {run_date} |", "| <added> |")  # the Candidates table's Added column
    return "\n".join(
        "- Added to the registry: <added>" if line.startswith(f"- Added to the registry: {run_date}") else line
        for line in text.split("\n")
    )


def dates_in(line: str) -> list[date]:
    found: list[date] = []
    for y, m, d in ISO.findall(line):
        try:
            found.append(date(int(y), int(m), int(d)))
        except ValueError:
            continue
    return found


def main() -> int:
    run_date = sys.argv[1]
    failures = 0
    for name in sys.argv[2:]:
        path = Path(name)
        text = path.read_text(encoding="utf-8")
        if run_date in masked(text, run_date):
            print(f"FAIL {path.name}: contains the run date {run_date} outside file names and added dates")
            failures += 1
        strict = path.name.endswith("-rows.csv") or path.name.endswith("-curves.csv")
        latest: date | None = None
        for number, line in enumerate(text.splitlines(), start=1):
            for d in dates_in(line):
                latest = d if latest is None or d > latest else latest
                if d > DEV_END:
                    if strict:
                        print(f"FAIL {path.name}:{number}: {d} after {DEV_END}: {line[:160]}")
                        failures += 1
                    else:
                        print(f"REVIEW {path.name}:{number}: {d}: {line[:160]}")
        print(f"ok-scan {path.name}: latest date {latest}")
    print("FAILURES", failures)
    return 1 if failures else 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Facts for the P7a docs, read from the committed rows CSV, plus an independent check of D8.

usage: python p7a_facts.py <rows.csv> <preregistration.md>

Prints a JSON object of the numbers the readme and ROADMAP templates need, and exits 1 when the CSV's
`eligible` flags or the finalists disagree with D8 recomputed here (handover D8: beats SPY TR, max DD
<= 15%, PF >= 1.3, >= 100 closed trades, no owner inputs; rank by MAR desc, ties by id; top 3, at most
one per family).
"""

from __future__ import annotations

import csv
import json
import math
import sys
from pathlib import Path

# Logical name -> phase 10's rows_csv column name. Adjust to `head -n 1` of the CSV.
COLS = {
    "id": "id",
    "family": "family",
    "rules": "rules",
    "start": "start",
    "end": "end",
    "total_return": "total_return",
    "cagr": "cagr",
    "max_drawdown": "max_drawdown",
    "profit_factor": "profit_factor",
    "trades": "trades",
    "mar": "mar",
    "spy_tr_total_return": "spy_tr_total_return",
    "spy_tr_cagr": "spy_tr_cagr",
    "owner_inputs": "owner_inputs",
    "eligible": "eligible",
}
# Divide by this to get a fraction (1.0 when the CSV stores fractions, 100.0 when it stores percent).
SCALE = {
    "total_return": 1.0,
    "cagr": 1.0,
    "max_drawdown": 1.0,
    "spy_tr_total_return": 1.0,
    "spy_tr_cagr": 1.0,
}
SEP = ";"  # separator inside the owner_inputs cell
TRUE = {"true", "yes", "1", "y", "eligible"}
NONE = {"", "none", "n/a", "na", "-", "—", "null"}
DD_MAX = 0.15
PF_MIN = 1.3
TRADES_MIN = 100
KEEP = 3


def num(row: dict[str, str], key: str) -> float | None:
    raw = row[COLS[key]].strip().rstrip("%")
    if raw.lower() in NONE:
        return None
    value = float(raw.replace(",", ""))
    return value / SCALE.get(key, 1.0)


def owner_inputs(row: dict[str, str]) -> tuple[str, ...]:
    raw = row[COLS["owner_inputs"]].strip()
    if raw.lower() in NONE:
        return ()
    return tuple(sorted(part.strip() for part in raw.split(SEP) if part.strip()))


def criteria(row: dict[str, str]) -> dict[str, bool]:
    tr = num(row, "total_return")
    spy = num(row, "spy_tr_total_return")
    dd = num(row, "max_drawdown")
    pf = num(row, "profit_factor")
    trades = num(row, "trades")
    return {
        "beats_spy": tr is not None and spy is not None and tr > spy,
        "dd": dd is not None and dd <= DD_MAX,
        "pf": pf is not None and (math.isinf(pf) or pf >= PF_MIN),
        "trades": trades is not None and trades >= TRADES_MIN,
        "owner": owner_inputs(row) == (),
    }


def main() -> int:
    rows_path, prereg_path = Path(sys.argv[1]), Path(sys.argv[2])
    with rows_path.open(encoding="utf-8", newline="") as f:
        rows = list(csv.DictReader(f))
    missing = [c for c in COLS.values() if rows and c not in rows[0]]
    if missing:
        print(f"columns not in the CSV header: {missing}; adjust COLS")
        return 2
    problems: list[str] = []
    counts = {"beats_spy": 0, "dd": 0, "pf": 0, "trades": 0, "owner": 0}
    eligible: list[dict[str, str]] = []
    for row in rows:
        c = criteria(row)
        for k, ok in c.items():
            counts[k] += int(ok)
        flagged = row[COLS["eligible"]].strip().lower() in TRUE
        if flagged != all(c.values()):
            problems.append(f"{row[COLS['id']]}: eligible={flagged} but criteria {c}")
        if flagged:
            eligible.append(row)

    def mar_key(row: dict[str, str]) -> tuple[float, str]:
        mar = num(row, "mar")
        return (-(mar if mar is not None else -math.inf), row[COLS["id"]])

    finalists: list[dict[str, str]] = []
    families: set[str] = set()
    for row in sorted(eligible, key=mar_key):
        if row[COLS["family"]] in families:
            continue
        families.add(row[COLS["family"]])
        finalists.append(row)
        if len(finalists) == KEEP:
            break

    prereg = prereg_path.read_text(encoding="utf-8")
    for row in finalists:
        if row[COLS["id"]] not in prereg:
            problems.append(f"finalist {row[COLS['id']]} is not named in {prereg_path.name}")
    if not finalists and "none eligible" not in prereg.lower():
        problems.append(f"no finalist, but {prereg_path.name} does not say 'none eligible'")

    ranked = sorted((r for r in rows if num(r, "mar") is not None), key=mar_key)
    best = ranked[0] if ranked else None

    def brief(row: dict[str, str]) -> dict[str, object]:
        return {
            "id": row[COLS["id"]],
            "family": row[COLS["family"]],
            "rules": row[COLS["rules"]],
            "start": row[COLS["start"]],
            "end": row[COLS["end"]],
            "total_return": num(row, "total_return"),
            "spy_tr_total_return": num(row, "spy_tr_total_return"),
            "cagr": num(row, "cagr"),
            "spy_tr_cagr": num(row, "spy_tr_cagr"),
            "max_drawdown": num(row, "max_drawdown"),
            "profit_factor": num(row, "profit_factor"),
            "trades": num(row, "trades"),
            "mar": num(row, "mar"),
            "owner_inputs": list(owner_inputs(row)),
            "failed": [k for k, ok in criteria(row).items() if not ok],
        }

    facts = {
        "n_trials": len(rows),
        "n_families": len({r[COLS["family"]] for r in rows}),
        "criteria_passed": counts,
        "n_eligible": len(eligible),
        "finalists": [brief(r) for r in finalists],
        "best_mar": brief(best) if best else None,
        "ref_spy_hold": next((brief(r) for r in rows if r[COLS["id"]] == "REF-SPY-HOLD"), None),
        "problems": problems,
    }
    print(json.dumps(facts, indent=2, sort_keys=True))
    return 1 if problems else 0


if __name__ == "__main__":
    sys.exit(main())
```
